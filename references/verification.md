# 测试说明

## 运行脚本测试

从工具包根目录运行：

```sh
python3 -m unittest discover -s tests -v
```

测试会检查机型配置、样本配对、配方冲突、草稿安装拦截、安装备份和XMP编辑保留。模拟样本用于检查代码，颜色效果用实际照片测试。

将`SONY_LOOK_SAMPLES`设为A9III实拍样本的samples.json路径，可运行四款外观的回归测试。其他机型用validate_samples检查自己的样本，并添加对应测试。

## 在LRC中检查

创建独立测试目录，使用照片副本。安装后先在增效工具管理器确认路径、版本和启用状态。

|项目|检查内容|
|---|---|
|普通导入|使用没有XMP的副本，导入时不应用预设，检查全部目标外观是否匹配正确|
|跳过照片|未知配方、不同机型，以及已手动选择其他配置的照片应保持原样|
|模块切换|从图库切换到修改照片，再切回，外观仍然有效|
|导出|导出的颜色正确，没有缺失配置提示，黑白外观保持黑白|
|已有编辑|曝光、白平衡、裁剪、蒙版、评级等保留，只改变外观和基础配置|
|虚拟副本|原版本保留原有编辑，副本应用对应外观|
|重启和重装|重启后外观正常，重装保留专用目录内的其他文件|
|不同光照|对照同次拍摄的机内JPEG，记录颜色偏差和需要调整的地方|

比较LRC导出和机内JPEG的色调、肤色、中性色、高光、阴影及细节，同时记录白平衡、曝光、DRO、镜头校正和输出色彩空间。另选一些场景检查，避免只对制作时用的照片调色。

SDK报告applied后，仍要查看实际图像。LRC首次导入可能稍后补齐Temperature、Tint等默认值，检查编辑是否保留时要区分这种变化。已有编辑测试使用明确设置过的数值。

如果Agent无法操作界面，或LRC暂时不可用，先完成脚本和安装计划，再列出用户要做的测试。未测试项保留pending，通过后改为passed。

## 完成后留下什么

个人安装包包含插件、配置、安装脚本、使用说明和测试记录。记录中写清机型、固件、系统、LRC版本、外观及光照条件。日常使用说明控制在一页，外观使用App名称，内部UUID保持稳定。

旧安装保存在运行数据目录的“安装备份”中。需要恢复时，先退出LRC，按安装记录还原插件和配置目录，再打开LRC。

测试完成后，将本次产生的照片副本移到废纸篓。个人照片、路径、LRC目录、缓存和日志留在个人项目中，分享时使用干净的工具包。
