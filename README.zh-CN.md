# Sony Creative Look to LRC

[English](README.md)

把Sony Creators’ App里下载的创意外观带进Lightroom Classic（LRC）。给本地AI助手一份配方截图和几张样片，它会为你的相机制作外观配置。相机文件里的信息足够区分配方时，插件可以在导入ARW后自动应用对应的外观。

第一次使用从[使用指南](开始使用.md)开始，把整个文件夹交给能访问本地文件、运行命令的助手即可。支持Skill的工具也可以把它安装为`sony-creative-look-to-lrc`。助手的操作步骤在[SKILL.md](SKILL.md)。

工具包附有用α9 III实拍制作的四款外观：电影人生、追光者、澄青、都市漫游。澄青和都市漫游都以FL3为基础，插件能根据拍摄时的配方参数自动区分。其他索尼机型需要用自己的原片做适配。 [查看实测记录](references/validation.json)

版本0.4.0。 [第三方代码和色彩资产](THIRD_PARTY.md)
