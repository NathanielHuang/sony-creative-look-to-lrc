# Third-party credits

The native color table reader and builder use [Sony Look Bridge](https://github.com/751K/sony-look-bridge) at commit `71a7422bff2a9ce921b747ea126d58445af8b242`. The base DCP builder also draws on its `acr_profiles.py` and `dcp.py`. The bundled code retains the [upstream MIT license](assets/project/SonyLooks.lrplugin/vendor/sony-look-bridge/LICENSE).

The [MIT license](LICENSE) covers the project's original code. The α9 III look names and recipes come from Sony Creators’ App. The color tables in the example XMPs were made from sample photos.

The installer builds the base DCP from a local Adobe profile or uses a compatible DCP supplied by the user.
