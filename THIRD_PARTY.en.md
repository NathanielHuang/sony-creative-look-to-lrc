# Third-party credits

This project uses code from [Sony Look Bridge](https://github.com/751K/sony-look-bridge) at commit `71a7422bff2a9ce921b747ea126d58445af8b242` to read and generate native color tables. The base DCP generator draws on its `acr_profiles.py` and `dcp.py`. The vendored copy retains the [upstream MIT license](assets/project/SonyLooks.lrplugin/vendor/sony-look-bridge/LICENSE).

The [project’s MIT license](LICENSE) covers original code. The look names and recipe settings in the α9 III adapter come from Sony Creators’ App. Its XMP profiles contain color tables generated from the author’s sample captures. These assets are listed separately from the code.

The toolkit contains no original photos, Adobe DCPs, or Sony applications. A personal installer builds its base DCP from a local Adobe profile or uses a compatible DCP supplied by the user.
