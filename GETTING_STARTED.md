# Getting started

[简体中文](开始使用.md)

## What to prepare

- Note your camera model and firmware version.
- Record each Creative Look recipe from Creators’ App, including its name, base look, all settings, and white balance fine-tuning.
- For each look, prepare one original ARW and its matching in-camera JPEG.

## Open the toolkit with your agent

Unzip the toolkit and open it in an AI agent. Tell it where to find the sample folder and give it a prompt like this.

> Read SKILL.md and help me set up my Sony Creators’ App Creative Looks in Lightroom Classic. Check my computer and sample photos, then build the profiles and install the plug-in once you have everything you need.

The agent reads the base look and recipe settings from the original files. Once it confirms that the recorded values can distinguish the looks, it sets up automatic matching after import.

## Use your looks in Lightroom

Import your ARWs as usual with **Develop Settings** set to **None**. Open Develop and check the applied profile. To match photos already in your catalog, select them and choose **Library → Plug-in Extras → 应用到选中照片** (Apply to Selected Photos). The plug-in menu is in Chinese.

Run your installer again after reinstalling Lightroom Classic. If you add a look, change cameras, or update the firmware, give the agent a fresh pair of sample photos.
