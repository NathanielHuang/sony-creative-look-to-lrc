# Getting Started

[简体中文](开始使用.md)

Use the new Creative Looks you downloaded from Sony Creators’ App when editing RAW photos in Lightroom Classic.

The agent starts by checking what look information your camera saves in its files. If the samples show that the recipes can be told apart, the plugin matches them after import. If they can't, the agent can set up profiles you select by name. It compares Lightroom exports with the camera JPEGs to check the color.

## Set up the tool

Extract the toolkit and open the folder with an AI agent that can access local files and run commands. Send it this message:

> Read SKILL.md and help me use my Sony Creators’ App Creative Looks in Lightroom Classic. Check my setup and sample photos, tell me what to prepare using the Getting Started guide, then build the profiles and install the plugin.

Follow the agent’s prompts for anything it still needs. It will build, install, and test your setup.

## What to provide

| Item | What to include |
| --- | --- |
| Camera | Model and firmware version |
| Recipe screenshots | Look name, base look, all settings, and white balance fine-tuning |
| Sample photos | At least one original ARW and matching in-camera JPEG per look, labeled with the look name |

The agent checks your operating system and Lightroom Classic version. It will ask if it can’t read them.

Copy the photos straight from the memory card. Put each look’s files in a folder named after the look, with its screenshots alongside them. Mention any differences between the actual white balance and the app’s recommendation.

Start with one pair per look. To check how the color holds up under different lighting, add daylight and indoor samples, plus a shot of the same scene with the camera’s default look.

## After setup

You’ll get an installer and instructions for your camera. Profiles use the names shown in Creators’ App. Import your photos as usual and continue editing the RAW files.

Run your installer again if you reinstall Lightroom Classic. If you add a look, update your camera firmware, or switch cameras, give the agent new samples to check.

The toolkit includes a tested Sony α9 III example. For another Sony model, the agent builds and tests an adapter using your original files.
